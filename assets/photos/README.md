# photos

The room currently uses illustrations instead of photographs. Nothing in this
folder is published. Only files inside `public/` reach the live site.

## If you add real photos later

Copy each file into `public/assets/photos/` with these names:

| File | Where it appears | Shape |
|---|---|---|
| `photo-1.jpg` | polaroid wall, top left | square crop |
| `photo-2.jpg` | polaroid wall, top right | square crop |
| `photo-3.jpg` | polaroid wall, bottom left | square crop |
| `photo-4.jpg` | polaroid wall, bottom right | square crop |
| `hero.jpg` | behind the letter | portrait, at least 900 px tall |

Keep each file under 300 KB so the page still opens fast on mobile data. Export
at 800 px on the long edge.

## Before you publish a photo

Ask her. A link on the internet is not the same as a photo in a drawer, even
when the page asks search engines to stay away. If a photo includes her face,
her friends, or a place she would not want named, use an illustration instead.
